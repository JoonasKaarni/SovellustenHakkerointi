# H0 Compile and Analyze

Aloitin Linux-koneella terminaalissa kirjoittamalla `vi filename.c` ja 
tiedoston sisälle tuli tämmöinen simppeli helloworld.

```c
#include <stdio.h>

int main() {
    printf("Hello World\n");
    return 0;
}
```
Sitten se compilettiin käyttäen gcc compileria komennolla `gcc filename.c –o filename`

Compiloinnin lisäksi luotiin tarvittavat tiedostot komennolla `gcc -Wall -save-temps filename.c –o filename`

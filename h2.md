## x)

### ffuf
ffuf:ia käytetään löytämään piilotettuja directoreja web serverillä brute-forceamalla URL polkuja sanalistan avulla.
Peruskäyttö: lataa ffuf `sudo apt install ffuf`, lataa sanalista, sitten aja `ffuf -w lista.txt -u http://sivu/FUZZ` ja pääset koittamaan tuhansia mahdollisia polkuja automaattisesti arvailun sijaan.

### OWASP Top Ten
Broken access control on OWASP Top Ten listan numeroyksi ongelma, joka löytyy jokaisesta testatusta sovelluksesta. Sen alle kuuluu force browsing, insecure direct object references, missing function-level access control, CORS-config ja cookie tampering.
Yleisimmät aiheuttajat sisältävät deny by defaultin käyttöönoton jättäminen, jolloin käyttäjä voi ylittää tarkistukset vaihtamalla URL:eja.

### PortSwigger
Access control määrittää mitä autentikoitu, sessioseurattu käyttäjä saa tehdä ja se jaetaan vertikaaliseen, horisontaaliseen ja contekstiseen.
Vertikaalisen oikeuden eskalointi tapahtuu, kun alhaisemman oikeuden käyttäjä saapuu vain korkeammin oikeutetuille tarkoitettuun toimivuuteen.

## b) Fix the 010-staff-only vulnerability from source code

Avasin staff-only.py -tiedoston ja vaihdoin sql-kohdan seuraavanlaiseksi.

Alkuperäinen oli `sql = "SELECT password FROM pins WHERE pin='"+pin+"';"`
Uusi `sql = "SELECT password FROM pins WHERE pin=:pin;"`

Alempaa tiedostossa muutin myös res-kohdan tämän näköiseksi:
`res = db.session.execute(text(sql), {"pin": pin})`

Sitten testaamiseen. Kokeilin samaa tekniikkaa kuin aikaisemmin, mutta tällä kertaa vastaus ei olekaan salasana vaan (not found).

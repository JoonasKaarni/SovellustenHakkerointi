# h3 No Strings Attached

## a)

Aloitin tehtävän lataamalla tarvittavat paketit ja tehtävään tarvittavan tiedoston.

`sudo apt-get update
sudo apt-get install unzip binutils gcc make upx-ucl
wget https://terokarvinen.com/loota/yctjx7/ezbin-challenges.zip
unzip ezbin-challenges.zip
cd challenges`

Tämän jälkeen menin challenges -kansion sisällä olevaan passtr -kansioon ja testasin suorittaa passtr -ohjelman.

<img width="674" height="149" alt="image" src="https://github.com/user-attachments/assets/c59b80cb-ae21-498d-a9a1-9197abece5f9" />

En tiennyt salasanaa, joten ei tullut bonusta. Jatkoin käyttämällä strings-komentoa tiedoston tutkimiseen.

`strings passtr | less`

Ja siellän näkyy jotain erittäin mielenkiintoista!

<img width="854" height="238" alt="image" src="https://github.com/user-attachments/assets/4440cdbd-cb7c-4d31-a3ca-a36fda4dce8d" />

password inputilla sala-hakkeri-321 näyttää tulevan FLAGi. Testasin tuota salasanaa ja näinhän se on!

<img width="888" height="126" alt="image" src="https://github.com/user-attachments/assets/bae594ea-d6c6-4926-b800-160ce65e6841" />

Oikea salasana ja FLAG löydetty.
